# Workspace Relative Links

When creating or modifying links to files within the workspace in markdown documents or responses:

- Always use root-relative paths starting with `/` (e.g., `[Label](/path/to/file.md)`).
- Do NOT use `file://` or absolute local filesystem paths (e.g., `file:///C:/Users/...`).
